## gpt6
All content in this directory except the initial `prompt.txt` was generated by GPT 6 Astra Pro.
Intermediate prompts were minimal.
For example:
> Make them even better.

with the one exception being
> There is new information about protein novelty assessment. Use that https://www.adaptyvbio.com/blog/novelty. Adaptyv will also running these novelty assessments for us during submission. Keep going.

The choice of GPT 6 for the Anthropic x Adaptyv challenge was not intended to be provocative.
Rather, this model hit the sweet spot on the Pareto frontier of output quality, cost to me, and biology safeguard rejections.
